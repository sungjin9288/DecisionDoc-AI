# 기술제안서: [합성] 문서관리시스템 고도화 제안서

## 기술 제안 요약
기술 제안의 핵심은 전자결재 완료 이벤트를 받아 문서를 자동 보관하는 연계 구조와, 보관된 문서를 형태소 분석 기반 전문 검색으로 찾게 하는 검색 구조입니다. 저장 단계에서 개인정보 포함 문서를 식별해 암호화하고, 모든 열람·다운로드를 접근 이력으로 1년간 보관합니다. 자동 분류는 사람이 확인하는 보조 기능으로 두어 오분류가 그대로 확정되지 않게 합니다. 각 구성 요소는 시범 부서 적용으로 동작을 확인한 뒤 전체에 적용합니다.

## 적용 기술
| 구성 영역 | 적용 기술 | 적용 목적 |
| --- | --- | --- |
| 결재 연계 | 전자결재 완료 이벤트 수신 API와 재처리 큐 | 결재 완료 문서 자동 보관과 누락 재처리 |
| 저장소 | 문서 본문·메타데이터 분리 저장과 버전 관리 | 최신본과 이력 동시 관리 |
| 검색 | 한국어 형태소 분석 기반 전문 검색 엔진 | 제목·본문·첨부 통합 검색 |
| 보안 | 저장 시 암호화와 접근 이력 로그 저장소 | 개인정보 보호와 감사 대응 |

## 시스템 아키텍처
전자결재 시스템이 결재 완료를 알리면 연계 모듈이 문서와 메타데이터를 받아 저장소에 보관하고, 실패한 건은 재처리 큐에서 다시 처리합니다. 저장 시 개인정보 식별 규칙을 적용해 해당 문서를 암호화하고, 검색 색인에는 권한 정보를 함께 기록해 사용자는 열람 권한이 있는 문서만 검색 결과로 봅니다. 열람과 다운로드는 모두 접근 이력 저장소에 기록되며 1년간 보관됩니다.

## AI 접근 방식
AI 기능은 문서 유형 자동 분류와 메타데이터(부서, 문서 종류, 보존 기간 후보) 추출을 보조하는 범위로 한정합니다. 추출 결과는 부서 문서 담당자가 확인한 뒤 확정하며, 확인 전 문서는 '분류 확인 필요' 상태로 표시합니다. 분류 정확도는 시범 부서 문서로 담당자 확인 결과와 비교해 측정하고, 기준에 미달하면 해당 유형은 수동 분류로 유지합니다.
