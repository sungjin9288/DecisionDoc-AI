# 기대효과: [합성] 문서관리시스템 고도화 제안서

## 효과 요약
본 사업의 기대효과는 결재 완료 문서의 보관 누락을 없애고 문서 검색 시간을 줄이는 것입니다. 검색 시간은 착수 단계에서 측정한 현행 소요 시간을 기준선으로 삼아 완료 시 같은 방식으로 비교하고, 보관 누락은 연계 대상 양식별 자동 보관 기록으로 확인합니다. 개인정보 암호화와 접근 이력 1년 보관으로 감사 대응 근거도 확보합니다.

## 사회적 가치
공공기관 문서가 누락 없이 보관되고 근거 있게 관리되면 기록 관리의 신뢰성과 행정 투명성이 높아집니다. 개인정보 보호 조치가 일관되게 적용되어 민원인과 직원 정보의 노출 위험도 줄어듭니다.

## 투자 대비 효과
사업비 1억 원(가상 금액) 대비 효과는 착수 시 측정한 검색 소요 시간과 결재 문서 이관 업무량을 기준선으로 삼아 완료 시 절감 시간을 산정합니다. 절감 시간 환산 금액은 기관의 인건비 기준을 확인한 뒤 계산하며, 근거 없는 금액은 제시하지 않습니다.
