# 사업 이해: [합성] 문서관리시스템 고도화 제안서

## 제안 요약
본 제안은 부서별로 흩어진 전자문서를 단일 저장소로 통합하고 전자결재와 연계해 결재 완료 문서를 자동 보관하는 문서관리시스템 고도화 방안입니다. 현재는 문서가 부서 공유폴더와 개인 PC에 나뉘어 있어 같은 문서를 찾는 데 반복적으로 시간이 들고, 결재 완료 문서의 보관 위치도 담당자마다 다릅니다. 이에 결재 연계 자동 보관, 전문 검색, 개인정보 암호화와 접근 이력 관리를 착수 후 6개월 안에 구축하고 관리자·사용자 교육으로 정착시킵니다. 검색 시간 단축 효과는 착수 단계에서 현행 검색 소요 시간을 측정해 기준선으로 고정한 뒤 같은 방식으로 검증합니다.

## 사업 배경
기관의 전자문서는 부서별 공유폴더와 개인 저장공간에 분산되어 있으며, 전자결재로 확정된 문서도 별도 보관 절차 없이 각 부서가 관리합니다. 이 구조에서는 최신본 확인과 이력 추적이 어렵고, 개인정보가 포함된 문서의 접근 통제도 일관되게 적용하기 어렵습니다. 본 사업은 결재 완료 문서의 자동 보관과 통합 검색을 통해 문서 관리 책임을 시스템 절차로 옮기고, 개인정보 암호화와 접근 이력 1년 보관 요구를 함께 충족하는 것을 배경으로 합니다.

## 현황 및 문제점
- 부서별 공유폴더와 개인 PC에 문서가 분산되어 동일 문서를 찾는 데 반복적으로 시간이 소요됨
- 결재 완료 문서의 보관 위치와 방식이 담당자마다 달라 최신본과 이력 확인이 어려움
- 개인정보가 포함된 문서의 암호화와 접근 통제가 부서별로 일관되지 않음
- 문서 접근 이력이 남지 않아 사후 확인과 감사 대응에 근거가 부족함

## 사업 범위
사업 범위는 전자결재 연계 자동 보관, 분산 문서 통합 저장소 구축, 전문 검색, 개인정보 암호화와 접근 이력 1년 보관, 관리자·사용자 교육 각 1회로 구성합니다. 사업 기간은 착수 후 6개월이며 사업비는 1억 원(가상 금액)입니다. 기존 문서 이관 대상과 순서는 착수 단계에서 부서와 협의해 확정합니다.
