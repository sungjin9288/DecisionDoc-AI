# [합성] 가상기관 문서관리시스템 고도화 사업 제안요청서

## Ⅰ. 사업 개요
- 사업명: 가상기관 문서관리시스템 고도화 사업
- 사업기간: 계약일로부터 6개월
- 사업예산: 금100,000,000원(금일억원), 부가가치세 포함(가상 금액)
- 수행사는 ISO-9001 인증 보유 여부를 제안서에 적는다.

## Ⅱ. 제안요청 내용
### 1. 요구사항 총괄표
| 구분 | 요구사항 고유번호 | 요구사항 명칭 |
|---|---|---|
| 기능 | SFR-001 | 전자결재 연계 자동 보관 |
| 기능 | SFR-002 | 통합 전문 검색 |
| 기능 | SFR-003 | 권한 기반 열람 제어 |
| 보안 | SER-001 | 개인정보 암호화 |
| 보안 | SER-002 | 접근 이력 1년 보관 |
| 프로젝트 지원 | PSR-001 | 관리자·사용자 교육 |

### 2. 요구사항 상세
- SFR-001 전자결재 연계 자동 보관: 결재 완료 문서를 사람 개입 없이 저장소에 보관한다.
- SFR-002 통합 전문 검색: 제목·본문·첨부를 함께 검색한다.
- SFR-003 권한 기반 열람 제어: 열람 권한이 있는 문서만 검색 결과에 보인다.
- SER-001 개인정보 암호화: 개인정보 포함 문서를 저장 시 암호화한다.
- SER-002 접근 이력 1년 보관: 문서 접근 이력을 1년간 보관한다.
- PSR-001 관리자·사용자 교육: 관리자와 사용자 교육을 각 1회 실시한다.

## Ⅲ. 제안서 작성 및 평가
### 1. 평가항목 및 배점
| 평가항목 | 배점 |
|---|---|
| 사업 이해도 | 10 |
| 기술 및 기능 | 40 |
| 보안 | 15 |
| 수행 관리 | 15 |
| 교육 및 지원 | 10 |
| 가격 | 10 |

### 2. 제출 조건
- 제안서는 PDF로 제출하며 전체 용량은 300MB 이하로 한다.
- 정량 제안서와 정성 제안서는 별도 파일로 제출한다.
- 정성 제안서 본문은 50쪽 이내로 작성한다.
- 블라인드 평가를 실시하므로 제안서에 제안사 명칭, 로고 등 식별 정보를 표기하지 않는다.
- 기술능력평가 점수가 배점한도의 85% 이상인 자를 협상적격자로 한다.

이 자료는 확인용 합성 데이터이며 실제 기관·사업과 무관하다.
