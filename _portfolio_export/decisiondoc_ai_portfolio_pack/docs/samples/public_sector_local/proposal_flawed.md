# [합성] 가상기관 문서관리시스템 고도화 사업 제안서

## 사업 이해도

1. 사업 배경
  가. 가상기관의 전자문서는 부서 공유폴더와 개인 저장공간에 나뉘어 있어 같은 문서를 찾는 데 반복해서 시간이 든다.
  나. 전자결재로 확정된 문서도 보관 절차가 정해져 있지 않아 최신본과 이력을 확인하기 어렵다.
2. 사업 목표
  가. 결재 완료 문서를 사람 손을 거치지 않고 저장소에 보관한다.
  나. 흩어진 문서를 한 저장소에서 제목·본문·첨부까지 검색한다.
  다. 개인정보 포함 문서를 암호화하고 접근 이력을 1년간 보관한다.
3. 사업 범위: 계약일로부터 6개월 동안 결재 연계, 통합 검색, 보안 기능을 구축하고 관리자·사용자 교육을 실시한다.

## 기술 및 기능

1. 결재 연계 구조
  가. 전자결재 완료 이벤트를 받아 문서와 메타데이터를 저장소에 보관한다.
  나. 보관에 실패한 건은 재처리 대기열에서 다시 처리해 누락을 막는다.
2. 검색 구조
  가. 제목·본문·첨부를 한 색인으로 묶어 검색한다.
  나. 색인에 열람 권한을 함께 기록해 권한이 있는 문서만 결과에 보인다.

## 보안

1. 개인정보 보호: 저장 단계에서 개인정보 포함 문서를 식별해 암호화한다.
2. 접근 기록: 열람·내려받기 이력을 별도 저장소에 기록하고 1년간 보관한다.
3. 권한 관리: 검색과 열람 모두 같은 권한 정보를 기준으로 판단한다.

## 수행 관리

1. 추진 체계: (주)가상솔루션이 사업관리, 연계·개발, 보안, 교육·전환 역할로 나누어 수행한다.
2. 추진 일정: 2026년 11월 2일 착수 후 착수·분석, 설계, 구축, 시범 적용, 완료의 5단계로 진행하며 각 단계는 완료 기준과 산출물 승인으로 넘어간다.
3. 위험 관리: 연계 사양 지연과 이관 문서량은 착수 단계에서 발주기관과 협의해 확정한다.

## 교육 및 지원

1. 관리자 교육: 저장소 운영, 권한 관리, 접근 이력 점검 방법을 다룬다.
2. 사용자 교육: 통합 검색과 결재 문서 조회 방법을 다룬다.
3. 교육은 관리자와 사용자 대상으로 각 1회 실시한다.

## 요구사항별 대응 방안

RFP 요구사항마다 대응 방안과 고유번호를 적는다.

### 전자결재 연계 자동 보관

SFR-001: 결재 완료 이벤트를 받아 문서를 자동 보관하고, 실패 건은 재처리 대기열에서 다시 처리한다.

### 통합 전문 검색

SFR-004: 제목·본문·첨부를 한 색인에서 검색한다.

### 권한 기반 열람 제어

SFR-003: 색인에 기록한 권한 정보로 열람 권한이 있는 문서만 검색 결과에 보인다.

### 개인정보 암호화

SER-001: 저장 시 개인정보 포함 문서를 식별해 암호화한다.

### 접근 이력 1년 보관

SER-002: 열람·내려받기 이력을 별도 저장소에 1년간 보관한다.

### 관리자·사용자 교육

관리자와 사용자 교육을 각 1회 실시한다. 교육 일정은 시범 적용 단계에서 발주기관과 정한다.
